# Guia de contribuição

Obrigado por contribuir com os projetos da Logika-Sciuro.

## Regras gerais

- descreva claramente o problema e a solução
- mantenha mudanças pequenas e objetivas quando possível
- atualize documentação junto com mudanças relevantes
- use mensagens de commit e PRs descritivas

## Pull requests

- explique contexto, solução e impacto
- referencie issues quando aplicável
- inclua evidências de teste quando relevante

## Documentação

- documentação local deve ficar próxima do código
- documentação transversal deve ser atualizada no portal central
